# 各处读同一份"有效证据"

> 来源：11-02 的外部审查（[报告](../../history/2026-11-audit/report.pdf)，括号里是报告的编号）。这是审查建议先定下来的四个接口里的"有效证据接口"；复盘和课程报告怎样随它失效，见 [结论跟着事实变](../../curriculum/proposals/2026-11-02-stale-conclusions.md)。修复顺序见 [PLAN](../../PLAN.md#6-开发路线)。

## 问题

- **掌握分析不算的作答，阶段报告还在算（L03）：** 老师核对后改正了一道题，learner 按规则把之前在这道题上的作答记为"不计"，状态是"未探测"；阶段报告（assess 的 `stageReport`）只读原始判分，仍判这个知识点"通过"，复盘也是"通过"，默认建议"进入下一阶段"。复盘只排除停用的题，改正后恢复使用的题照算。答题时看过答案（"有帮助"）的作答，learner 记为有帮助完成，阶段报告也照样算通过。
- **同一个事实，几处各算各的：** 掌握状态、阶段报告、复盘、课程报告分别解释作答和判分，只有 learner 用了"改判、题目改正、帮助"这些规则。
- **整理课堂记录失败的那段对话，当作没有帮助（M03）：** 主老师的课堂记录和侧边会话的总结，连续失败几次后跳过那一段（课堂记录推进游标，侧边会话存一个 `skipped` 段）。那段对话里讲过的东西不记帮助，之后的作答就被当成独立完成。

## 方案

1. **learner 提供有效证据的查询：** 给一组作答（或一份测试），返回每条作答的原始判分、当前有效的判分（沿改判找到最后一次）、是否计入和原因（题目改正或停用、待复核、有申诉没处理）、独立还是有帮助（哪种帮助）、是不是新题，以及算这些用的规则版本和日志条数。规则就是 learner 现在算掌握状态的那一套，抽出来共用，不另写一份。
2. **阶段报告、复盘、课程报告都读它：**
   - assess 的阶段报告和结课检验结果用"有效判分"：不计的作答不支持"通过"，这个知识点按"证据不够"；有帮助的作答单独标出，结论写"有帮助完成，还要独立验证"，不算通过；
   - curriculum 的复盘事实和课程报告同样读它（复盘的风险携带见 [结论跟着事实变](../../curriculum/proposals/2026-11-02-stale-conclusions.md)）；
   - 历史试卷照常显示原始判分，旁边写明现在不计的原因。
3. **帮助状态"不确定"（M03）：** 课堂记录或侧边会话总结跳过的那段对话，记一条"这段没整理"（时间范围、会话、原因、用的模型）。在那段时间里或之后 24 小时内、涉及同课程的作答，帮助状态记"不确定"：不当独立，也不当有帮助；说明写"那段对话没整理成功"。提供重试整理的入口（老师工具或页面按钮），整理成功后按结果重算。
4. 契约（[contracts.md](../../contracts.md)）写明：作答事实归 assess，有效证据由 learner 算，别的单元只读这个查询，不自己解释判分。

## 放弃的方案

- **在阶段报告里复制一份"题目改正就不计"的判断：** 规则会继续改（帮助、新题、申诉），复制的地方会和 learner 再次不一致。
- **题目改正时直接删掉或改掉旧作答：** 证据只追加、不修改（10-03 的决定）；旧作答和原始判分要能查到，只是不再支持结论。
- **整理失败时默认算"有帮助"：** 那段对话可能只是闲聊，全部当帮助会冤枉之前和之后的独立作答；"不确定"如实说明。

## 验收标准

1. 先答对、再由老师改正题目：掌握状态、阶段报告、复盘事实、课程报告都不再把这条作答当通过的依据，各处的说明一致；历史试卷仍显示原始判分和不计的原因。
2. 答题前看过答案的作答：掌握状态是"有帮助完成"，阶段报告不判这个知识点"通过"。
3. 课堂记录连续失败、跳过一段后，紧接着的作答说明里写"帮助状态不确定"；重试整理成功后按结果重算，前后一致。
4. 删掉 learner 的状态表重算，各处结果不变。
5. `pnpm typecheck`、`pnpm test`（含 `tests/flow.test.ts`）、`pnpm build` 通过。

## 风险

- assess 读 learner 的查询，依赖方向和现在相反（现在 learner 只听 assess 的事件）；用 `ctx.get` 按需取，learner 没加载时阶段报告退回原始判分并标明"没算有效证据"。
- "不确定"会让一部分知识点更晚达到"独立完成"；试用时看看比例。
- 帮助"不确定"的时间范围（24 小时）沿用现在的帮助规则，以后和那几个参数一起校准。
