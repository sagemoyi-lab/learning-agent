# 题源要有凭据，每种测试都按它的计划组卷

> 来源：11-02 的外部审查（[报告](../../history/2026-11-audit/report.pdf)，括号里是报告的编号）。修复顺序见 [现在](../../now.md#修复顺序)。知识点合并后组卷找不到题（L14）见 [知识身份一致](../../knowledge/proposals/2026-11-02-identity-consistency.md)。

## 问题

- **"权威题"只凭老师自报（L02）：** `add_problems` 里 `tier: 2`（权威来源）的 `chunkId` 是可选的，`answerSource: 'authority'` 也照单全收。没有出处、答案也没有依据的题，可以存成"原创、二级、权威答案"并进测试预留池，成为阶段测试和结课检验的证据。存题时只拒绝四级和"未核对"，不检查二级和出处、答案依据对不对得上。
- **指定题目就跳过了计划（L04）：** `start_test` 填了 `problemIds` 时不构建阶段测试的蓝图（`plan`）和结课检验的目标对应（`final`）。这样发出的阶段测试交卷后进入"复盘中"，却没有阶段报告，`save_stage_review` 报"找不到判过分的阶段测试"，阶段卡住；指定题目的结课检验也认不出是哪次。这条路还跳过了"只用没见过的题"的检查。
- **结课检验换题后，目标条目还指着旧题（L16）：** 换题时更新了试卷、阶段计划和模拟考的分组，漏了结课检验每个目标条目的题目列表。你报"这题做过"换了一道并答对，报告仍说这一条"没测到"。

## 方案

1. **出处和答案依据由凭据推出（L02）：**
   - 二级题必须带有效的资料片段（属于本课已加入的资料），出处由片段生成；没有片段的最多是四级（原创），只能进练习题池；
   - 答案依据由程序推出：片段里有答案（或老师指出答案所在的片段）才是"权威"，有计算过程是"已验算"，其他是"未核对"；不再接受模型直接写 `authority`；
   - `import_exercises` 里老师手工改的答案同样区分"解析修正""老师推算"和"核对过原文"；
   - 这些检查放在存题的服务里，不只在工具里。
2. **每种测试的计划是必填的（L04）：** 契约里按测试种类写成不同的类型：阶段测试必须有蓝图，结课检验必须有目标对应和阶段，模拟考必须有分组。指定题目时程序照样构建计划（检查题都是没见过的测试预留题、覆盖了核心知识点），不满足就发布前报错；只有小测、练习这类不需要计划的测试可以只给题目。
3. **换题统一维护所有计划（L16）：** 换题写成一个操作，同时更新试卷、阶段蓝图、模拟考分组和结课检验的目标条目；跳过不换时，把对应条目标成"没测到"并写原因，不留指向旧题的引用。

## 放弃的方案

- **只在老师提示词里强调"二级题要带出处"：** 规则写在提示词里，模型照样可能不守；必须在存题时由代码检查。
- **禁止老师指定阶段测试的题目：** 老师有时需要指定某道完整任务题；保留指定，但计划照样构建和校验。

## 验收标准

1. 没有片段、片段不在本课资料里、答案找不到依据的二级题，进不了测试预留池；有片段并给出答案位置的照常入池，测试页能看到出处。
2. 阶段测试、结课检验、模拟考、小测、练习，各自用自动选题和指定题目两种方式走完发布 → 作答 → 交卷 → 复盘或报告；阶段测试一定能保存复盘，结课检验一定有按目标条目的结果；不满足计划的指定题目在发布前报错。
3. 结课检验里换一次、换两次、跳过不换，报告里每个目标条目的题号和结果都对应真实的试卷；阶段测试和模拟考的换题行为不变。
4. `pnpm typecheck`、`pnpm test`（含 `tests/flow.test.ts`）、`pnpm build` 通过。
